O que é a cotação?

É a relação de valor entre duas moedas. Por exemplo, se a cotação for de 5,00 significa que uma unidade da moeda base corresponde a 5 unidades da moeda desejada.

Fonte dos dados

Os dados das moedas são consultados pela API Frankfurter,por isso podem ser diferentes das taxas usadas por bancos.
